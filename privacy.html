Privacy Policy

FurkAI YouTube Publisher - last updated 30 October 2026

Who this applies to

FurkAI YouTube Publisher is a private desktop tool operated by Furkan Hatipoğlu for his own YouTube channels (eight channels, all owned by the operator). It has no other users, is not distributed, and does not collect data from the public.

What the tool accesses

When the operator signs in with a Google account, the tool requests these YouTube permissions for that account's own channel only:

  • upload videos (youtube.upload),
  • read basic channel information (youtube.readonly),
  • manage the operator's own videos and comments (youtube.force-ssl): set thumbnails, upload captions, add videos to the operator's own playlists, change a video's privacy or publish time, and post a poll comment on the operator's own video,
  • read channel analytics such as views and watch time (yt-analytics.readonly).

How the data is used

The access is used only to upload and manage the operator's own videos and to measure how they perform. It is not used for advertising, profiling or any other purpose. The tool never reads or stores data about other YouTube users.

Storage and sharing

Authorization tokens are stored only on the operator's own computer. No Google user data is sold, shared with, or transferred to third parties.

Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services, so the YouTube Terms of Service and the Google Privacy Policy also apply.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. To ask for deletion of any stored authorization data, contact htpfurkan@gmail.com.
